# Getting help

DCAT-AP-UK is a proposal, maintained in the open. There is no service level.

- **How do I…?** Start with the [user guide](https://cyberdudeuk.github.io/dcat-ap-uk/guide.html) and the [tutorials](https://cyberdudeuk.github.io/dcat-ap-uk/tutorials.html).
- **Something is wrong:** open a [defect](../../issues/new?template=defect.yml).
- **Change the profile:** open a [change request](../../issues/new?template=change-request.yml), or use "Suggest a change to this page" in any page footer.
- **My product conforms:** open a [conformance claim](../../issues/new?template=conformance-claim.yml) with the kit results.
- **Anything else:** the [contact form](https://cyberdudeuk.github.io/dcat-ap-uk/contact.html).
- **A security problem:** see [SECURITY.md](SECURITY.md). Do not open a public issue.

Please do not include personal data or anything above OFFICIAL in issues.
