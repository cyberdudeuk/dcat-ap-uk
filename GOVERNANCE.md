# Governance

DCAT-AP-UK is **proposed, not endorsed**. It is not an official GOV.UK service or policy.

## Roles

- **Owning team:** decides changes, publishes releases and keeps the registers.
- **Metadata Implementation Working Group:** reviews major and minor changes.
- **Data Standards Authority:** endorses major changes, if and when the profile is put forward.
- **Maintainers:** review pull requests and keep the release gate green.
- **Repository owner:** settings only the owner can change (see [docs/repo-settings.md](docs/repo-settings.md)).

Roles, not names: no person is named as an owner, steward or contact.

## How a change is made

Proposal (issue form) → assessment (major, minor or patch) → discussion → decision → release, with a test and a deliberate break.
The full process, the decisions (ADRs), the defect register and the open register are on the
[governance page](https://cyberdudeuk.github.io/dcat-uk-ap/governance.html) and in [docs/registers.md](docs/registers.md).

## Versioning

Semantic versioning. A major version breaks existing records; a minor version adds; a patch fixes wording.
The previous release stays published.
