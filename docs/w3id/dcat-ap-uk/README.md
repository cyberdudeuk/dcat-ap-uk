# DCAT-AP-UK on w3id.org

Persistent identifiers for DCAT-AP-UK, the DCAT Application Profile for the UK: a proposal, not endorsed and not an
official GOV.UK standard.

- Maintainers: the DCAT-AP-UK maintainers (GitHub account cyberdudeuk), through https://github.com/cyberdudeuk/dcat-ap-uk/issues
- Portal: https://cyberdudeuk.github.io/dcat-ap-uk/

| Identifier | Resolves to |
|---|---|
| `https://w3id.org/dcat-ap-uk/ns#{term}` | Terms the profile adds (Turtle, JSON-LD or the property pages) |
| `https://w3id.org/dcat-ap-uk/codelist/{list}/{code}` | Codelist values (Turtle, JSON-LD or the codelist page) |
| `https://w3id.org/dcat-ap-uk/ext/{id}` | Sector extensions |
| `https://w3id.org/dcat-ap-uk/shapes`, `/schema`, `/context` | SHACL shapes, JSON Schema, JSON-LD context |
| `https://w3id.org/dcat-ap-uk/{version}` | A version of the profile |

Submitted to w3id.org as https://github.com/perma-id/w3id.org/pull/7100 (one file, `ids/dcat-ap-uk/.htaccess`; maintainer contact is in its comments). Keep this copy in step with the one there.
