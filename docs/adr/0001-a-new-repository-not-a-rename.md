# ADR 0001: A new repository, not a rename

Status: Accepted

## Context

Issue 78 asked whether to rename the xGov MEM repository. Its discussion said a completely new solution suits a new repository.

## Decision

Start a new repository (first cyberdudeuk/dcat-uk-ap, renamed cyberdudeuk/dcat-ap-uk on 6 November 2026; GitHub redirects the old name). Keep every xGov MEM slot in the crosswalk. Propose archiving the old repository with a pointer, once the owners agree.

## Consequences

Old issue links keep working. Records written to the xGov MEM convert with the validator.
