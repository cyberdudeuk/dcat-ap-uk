# ADR 0001: A new repository, not a rename

Status: Accepted

## Context

Issue 78 asked whether to rename the xGov MEM repository. Its discussion said a completely new solution suits a new repository.

## Decision

Start a new repository (cyberdudeuk/dcat-uk-ap, to be renamed dcat-ap-uk: open register O-16). Keep every xGov MEM slot in the crosswalk. Propose archiving the old repository with a pointer, once the owners agree.

## Consequences

Old issue links keep working. Records written to the xGov MEM convert with the validator.
