# ADR 0014: A global bar that fits a laptop screen

Status: Accepted

## Context

With eleven items the bar folded About, Downloads and Estate into More below about 1,400 pixels, so most laptop users needed an extra click and could not see where About was.

## Decision

What has changed and Strategy become one Context menu. Help leaves the bar: the masthead Help button leads to the user guide, which links the tutorials and roles, and it is marked when you are on those pages. Help stays in the site map and llms.txt.

## Consequences

Nine items fit at 1,280 pixels with room to spare, checked in the browser at 1,280, 1,440 and 1,920 pixels (break: fold).
