# ADR 0010: Quantum-ready means ready to migrate

Status: Accepted

## Context

Post-quantum migration is a long programme (NCSC: discovery by 2028, completion by 2035). Metadata cannot make data quantum-safe.

## Decision

Record algorithms as identifiers, warn on weak checksums, and record connection security on data services so the catalogue helps the inventory.

## Consequences

The pages say plainly what the profile does not do.
