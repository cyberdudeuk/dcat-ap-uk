# ADR 0004: Obligations for critical data assets as conditionals

Status: Accepted

## Context

The April 2026 guidance asks for more for critical data assets than for other data.

## Decision

A critical data asset flag switches on extra mandatory properties, in the same record, rather than a second profile.

## Consequences

One record serves the catalogue and the return. SHACL and JSON Schema both express the rule.
