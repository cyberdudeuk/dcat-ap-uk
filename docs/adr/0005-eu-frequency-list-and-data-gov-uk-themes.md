# ADR 0005: EU frequency list and data.gov.uk themes

Status: Accepted

## Context

DCAT-AP uses the EU frequency vocabulary; the xGov MEM used Dublin Core terms. Issue 49 proposed the data.gov.uk topics for themes.

## Decision

Use the EU frequency list, converting Dublin Core values. Use the 14 data.gov.uk topics for themes, mapped to EU data themes.

## Consequences

UK records harvest into European tools. The mappings are the author's and need review (open register O-04).
