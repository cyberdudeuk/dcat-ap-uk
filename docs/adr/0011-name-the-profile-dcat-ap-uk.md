# ADR 0011: Name the profile DCAT-AP-UK

Status: Accepted

## Context

National profiles of DCAT-AP are named DCAT-AP- and a country code (DCAT-AP-NO, DCAT-AP-SE, DCAT-AP-NL, DCAT-AP-DE). The draft was called DCAT-UK AP.

## Decision

Call it DCAT-AP-UK, the DCAT Application Profile for the UK, in every page, file and namespace. Keep the dcatuk: prefix for terms.

## Consequences

The w3id namespace becomes https://w3id.org/dcat-ap-uk/. The repository keeps its old name until the owner renames it (O-16).
