    Vendor connectors and AI agents

    New This page is new since 1.2.0-rc.1 (2026-11-06). Everything that changed

    The products that analysts rank for data catalogues, metadata management and data governance, and the platforms that carry catalogues inside them. For each one: where its code and metadata model are published, how its fields map to DCAT-AP-UK, an add-on kit for the properties it lacks, and what it offers AI agents through the Model Context Protocol. Live connectors need a tenant and its credentials, so the portal ships kits and conversions rather than calling any vendor's service.

    • 19 MCP servers
    • 18 entries in Claude
    • Checked 2026-11-07

    Nothing here is a test, an endorsement or a ranking by this project, and no kit has been tried against a live tenant. Positions in paywalled analyst reports come from the vendors' own announcements, labelled S, or from secondary sources, labelled K. Suppliers can correct an entry with the claim form on the integrations page.

    Atlan

    Mapped Kit Weaver MCP In Claude Runs as: SaaS S. Single-tenant SaaS on AWS, Azure or Google Cloud; a self-deployed runtime runs connectors inside the customer's network. (source, checked 14 November 2026.) In: Gartner metadata management 2025, Gartner D&A governance 2025, Forrester data governance 2025, Forrester data catalogues 2024

    How to connect
    1. Add the DCAT-AP-UK properties to Atlan: load Business metadata typedef (Apache Atlas, Microsoft Purview, Atlan). Custom metadata, sent to the typedef API as businessMetadataDefs (pyatlan/model/typedef.py). Atlan addresses custom metadata by internal names in its API, so map the kit's names to them when loading.
    2. Convert records both ways in the metadata weaver (choose Apache Atlas (Microsoft Purview, Atlan)), or in a pipeline: node integrations/cli/validate.js --from atlas export.json checks an export as DCAT-AP-UK.
    3. Give AI agents the catalogue through its MCP server: Hosted MCP server at mcp.atlan.com/mcp with OAuth; the local server in the repository is deprecated and in maintenance only.
    4. In Claude: Atlan (plugin). See In Claude.
    5. Check every record against DCAT-AP-UK with the validator before it is published or harvested.
